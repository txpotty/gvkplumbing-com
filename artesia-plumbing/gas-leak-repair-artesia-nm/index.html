    Corrugated Stainless Steel Tubing Repair in Artesia, NM

    CSST is the yellow-jacketed flexible tubing used in many newer homes, and it can be damaged by a nearby lightning strike if it was never bonded. Repairs use the same brand's fittings as the existing tubing, since manufacturers do not allow mixing parts. A splice that skips that rule fails the inspection.
